# Report Project

This folder is a standalone LaTeX report project for Overleaf.

## Files

- `main.tex`: report source
- `references.bib`: bibliography
- `figures/`: copied local figure assets used by the report

## Overleaf

Upload the whole `report/` folder or the generated zip archive to Overleaf.

## Notes

- The current author block is a placeholder and can be edited in `main.tex`.
- The report is written to match the grading rubric in `RL_Final_Project_Rubric.pdf`.
